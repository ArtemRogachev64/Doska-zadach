# Доска задач

Одностраничное приложение (SPA) на React — канбан-доска для управления задачами.
Проект собран на Vite, внешних зависимостей кроме React нет.

## Возможности

- **Колонки**: создание, переименование (клик по названию), удаление с подтверждением.
- **Порядок колонок**: перетаскивание за иконку в заголовке колонки.
- **Задачи**: создание, редактирование (название и описание) и удаление.
- **Перетаскивание задач**: между колонками и внутри колонки, на любую позицию.
- **Сохранение**: состояние доски автоматически хранится в `localStorage`.
- **Сброс**: кнопка в шапке возвращает доску к начальному набору.
- Светлая и тёмная темы (автоматически по настройкам системы).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка и проверка:

```bash
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр сборки
npm run lint     # oxlint
```

## Структура

```
src/
  App.jsx                     шапка, счётчики, сброс доски
  index.css                   все стили и дизайн-токены
  hooks/
    useBoard.js               состояние доски (reducer) + сохранение в localStorage
  components/
    Board.jsx                 сетка колонок и вся логика drag & drop
    Column.jsx                колонка: заголовок, список задач, добавление
    TaskCard.jsx              карточка задачи
    TaskModal.jsx             модальное окно создания/редактирования задачи
    ConfirmDialog.jsx         диалог подтверждения удаления
    icons.jsx                 набор SVG-иконок
```

## Как устроен drag & drop

Используется нативный HTML5 Drag and Drop API, без сторонних библиотек.

- При `dragstart` в `dataTransfer` кладётся id задачи или колонки.
- Во время `dragover` по позиции курсора вычисляется индекс места вставки, и
  рисуется индикатор (линия между карточками или полоса между колонками).
- В `drop` данные читаются напрямую из `dataTransfer`, поэтому перемещение не
  зависит от состояния React и не сбоит при быстром перетаскивании.
- DOM во время перетаскивания не перестраивается — источник остаётся на месте
  (подсвечен), что делает поведение предсказуемым в разных браузерах.
